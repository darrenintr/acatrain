Principles

01
Split every move into space and effectTransform rides a spatial spring; opacity and colour ride the effects spring so fades never bounce.
02
Springs, not durationsEach token is stiffness + damping. The ms shown is only when it settles; interruptions retarget with velocity.
03
Exits are quicker than entrancesOut: 180–200 ms accelerate. In: 430 ms expressive. The next thing is already arriving as the last leaves.
04
Short, capped staggers40 ms between siblings, never more than 280 ms total, so a screen is readable in half a second.
05
Small travel12 dp entrance lift, 0.97 press, 0.965 flip dip. Nothing moves further than it needs to.
06
Overshoot is earnedOnly the fast expressive spring overshoots visibly (≈9%): badges, chips, the button squash. Content never wobbles.
07
Loops must mean “live”Only progress waves and the due badge move continuously, slowly. The streak flame flickers once, not forever.
08
Reduce motionEvery animation collapses to its end state instantly; colour changes still cross-fade for clarity.
