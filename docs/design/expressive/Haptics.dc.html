Principles

01
Only for things the user didNever on screen load, scroll, count-ups, loops or content arriving by itself.
02
Always paired with something visibleA haptic confirms a change the eye can also see; it never carries meaning alone.
03
Lands with the motionPulses are timed to the visual peak: the flip lands at 220 ms, the shake pulses on its peaks.
04
Light by defaultMost actions are a single tick or tap. Rich patterns are reserved for results: confirm, reject, celebrate.
05
Wrong is gentle“Again” is a soft low tick. Only a wrong test answer uses a reject pattern, and it decays quickly.
06
One at a timeAt most one pattern per 80 ms; a new one cancels the previous. Celebrate plays at most once per session.
07
User controls strengthOff · Subtle (×0.6) · Standard. System haptics off always wins.
08
Silent where it can’t be feltDesktop, web and devices without a haptic motor: no-op, no fallback beep.

Strength setting

OffNo haptics
SubtleScales and intensities × 0.6
StandardDefault. Values as specified

Set in Settings → Feel. Stored per device, not synced.

Sync example: wrong answer

The row shake is a damped sine over 420 ms. Four haptic pulses land exactly on its first four peaks and fade with it, so the hand and eye feel the same event.
